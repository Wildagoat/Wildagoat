### Selected Projects

| Project | What it is |
| --- | --- |
| **[CV Punch Trainer](https://williamdong.dev/games/punch-trainer)** | Real-time, in-browser boxing-form coach — MediaPipe pose + a custom biomechanics engine that scores every punch. Runs fully on-device. |
| **[Personal Site](https://github.com/Wildagoat/williamdong.dev)** | No-build, vanilla-JS portfolio with interactive 3D CAD models and a hidden drift game. Deployed on Vercel. |
| **[Cycloidal Drive FS](https://github.com/Wildagoat/cycloidal-drive-featurescript)** | An Onshape FeatureScript that generates a complete cycloidal reducer disk parametrically, straight from the drivetrain geometry. |
| **[Kodawari](https://github.com/Wildagoat/kodawari)** | Boxing motion-analysis pipeline: pose &rarr; biomechanical features &rarr; critical-moment detection &rarr; per-dimension scoring. |
| **[Fight Diagram](https://github.com/Wildagoat/fight-diagram)** | Browser tool for diagramming and animating boxing positioning — paths, arrows, telestrator, PNG/WebM export. |
| **SCORPION** *(hardware)* | Attritable ground vehicle — lead &amp; sole ME at Raptor Defense. Concept &rarr; 50+ mph prototype in 9 days, on half the R&amp;D budget. |
| **FTAD Chassis** *(hardware)* | Reference RC race-car chassis for the F1-inspired engineering competition I founded. Full independent suspension, refined with CFD + topology optimization. |
